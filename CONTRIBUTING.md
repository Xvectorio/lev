# Contributing

Issues and pull requests are welcome.

- **CLA required.** Before a pull request can be merged, you must sign the [Contributor License Agreement](CLA.md). The CLA bot comments on your first pull request with the sentence to post; you sign once, for all future contributions. The CLA lets Xvector offer Lev under commercial licenses as well as the AGPL-3.0; you keep your copyright.
- **Everything runs in Docker.** See `CLAUDE.md` for the build, test and Vector check commands. Run `docker compose run --rm test` and `docker compose -f compose.tools.yaml run --rm vector-test` before opening a pull request.
- Keep `README.md` in sync when behavior changes.
